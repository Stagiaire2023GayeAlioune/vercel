## Déploiement Vercel

1. Pousser le projet sur **GitHub**
2. Aller sur [vercel.com](https://vercel.com) → **Add New Project**
3. Importer le repo GitHub
4. Framework : **Next.js** (détecté automatiquement)
5. Cliquer **Deploy**

Aucune configuration supplémentaire requise.
